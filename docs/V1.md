# Local v1 scope

A reusable NixOS module and an on-host operations command for three fixed games.
The source is a clean remake. The original disk installer and remote-sync
framework are deliberately outside this release.

Included: distinct service users/state, private settings credentials, opt-in
firewall/boot start, resource ceilings, explicit updates, local quiesced snapshots,
per-game operation locks and restore-check extraction. A fixture VM verifies real
systemd mechanics. Unit tests cover corruption, unsafe archives and failure paths.

Deployment acceptance remains separate: download the actual game, confirm native
or Wine startup, join with a client, restart the host, and recover an actual saved
world. Those checks have not been performed for this remake. Local v1 does not
mean production or vendor compatibility certification.

Deferred: disk provisioning, arbitrary/multiple instances of one game, public
RCON, remote upload/deploy scripts, scheduled patching/restarts, encrypted remote
backup delivery, retention/pruning, binary-version pinning/rollback and a web UI.
Keep this scope closed while the portfolio case studies and selected projects
are brought together.
